# Expo SDK

This project runs on Expo SDK 54 (`react` 19.1.0, `react-native` 0.81.5) — pinned intentionally because the team's Expo Go app only supports up to SDK 54. Don't bump `expo`/`react`/`react-native`/`react-native-*` without checking that constraint first. See CLAUDE.md for the full picture.
